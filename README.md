# Volzybeats
volzybeats.com

## Project structure

```text
public/
  audio/       Audio tracks and other downloadable audio
  images/      Public images and artwork
src/
  components/  Reusable interface components
  data/        Portfolio content and track metadata
  pages/       Website pages
  styles/      Global and component styles
```

This framework-neutral structure separates website code from public portfolio
assets. Add files to these directories as the site is developed.
